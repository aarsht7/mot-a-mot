# Credits and licensing

## Vocabulary

The main set of French–English words and expressions is adapted from **Universal Foreign Language Flashcards** (UFLF), maintained by Darigov Research, itself based on **Français Interactif** from the Center for Open Educational Resources and Language Learning (COERLL), University of Texas at Austin.

- Source: https://github.com/darigovresearch/Universal-Foreign-Language-Flashcards
- Underlying course: https://www.laits.utexas.edu/fi/
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

**Modifications:** The vocabulary entries are deduplicated, grouped into *approximate* study levels, annotated with best-effort part-of-speech and noun-gender metadata, combined with independently authored B1–C1 vocabulary, and displayed as an interactive learning deck. English meanings from the source have not undergone a full editorial review. The original source does not assign the A1–C1 groupings used here. Some cards are multiword phrases and can have multiple English senses. Please report errors and verify ambiguous grammatical details.

## Verb data

The build uses [french-verbs](https://www.npmjs.com/package/french-verbs) (Apache-2.0) and [french-verbs-lefff](https://www.npmjs.com/package/french-verbs-lefff), the latter drawing on **Lefff**, distributed under LGPL-LR for linguistic resources. The generated verb inflection data retains the data-source attribution and applicable license. The website displays only supported forms and links to an external reference when a form is missing. Auxiliaries and past-participle agreements can vary with context.

## Code

The website code (HTML, CSS, app logic, data processing scripts and original C1 additions) was specifically written for this project. The code may be reused subject to preserving attribution for the separately licensed vocabulary and verb inflection data.
